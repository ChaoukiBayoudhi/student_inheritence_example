# Student inheritance example

A java example that shows inheritance.

## Tech stack

- Java (no build tool: plain source files)

## Concepts covered

Console input (Scanner), inheritance.

## Project structure

- `src`: Main, Student, StudentTerminal

## How to run

Open the folder in IntelliJ IDEA or Eclipse and run `Main` (it contains the `main` method).
